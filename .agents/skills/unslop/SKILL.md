# unslop

Transform "vibecoded," generic AI-generated interfaces into polished, intentional, human-crafted designs with authentic character.

Created by Damir Sokolovsky (@heydamir), licensed under CC-BY-4.0.

## Core Philosophy

1. **Slop Tells:** AI models gravitate toward predictable aesthetic clichés:
   - Neon/cyan and purple gradients, gradient text, glow dropshadows.
   - Emoji badges (`✨ New`, `🔥 Popular`), arbitrary pill tags above headings.
   - Glossy floating orbs, hollow bento grids, glassmorphism on everything.
   - Vague marketing fluff copy, exclamation marks, and exaggerated claims.
   - Erratic, inconsistent spacing and typography.

2. **The Rule of Richness:**
   Removing ornaments is only half the job. A stripped page that could belong to any product is just an empty template.
   Quiet down the chrome (subtle hairline borders, neutral surfaces) and concentrate richness into 1-2 memorable, genuine focal points (real photography, live interactive tools, precise real data).

## The Workflow

### Phase 1: The Audit
Inspect the screen or code and list the specific "slop tells" found (spacing, colors, copy, icons, unnecessary cards).

### Phase 2: Creative Direction (5 Lines)
Before touching code, draft a 5-line direction grounded in the actual product domain:
1. **Subject:** What this business/product actually is and its real-world constraints.
2. **Palette:** Restrained neutral ramp + 1-2 intentional, authentic accent tones (no synthetic neon/glows).
3. **Typography & Voice:** Clear hierarchy, grounded tone, zero hype words or filler subtitles.
4. **Visual Weight:** Authentic media (real photos, real data) over artificial decorative blobs.
5. **Structure:** Clear 8px grid rhythm and single primary call to action.

*Wait for user approval before writing changes.*

### Phase 3: The 9 Ordered Passes
Once approved, execute changes in this strict order:
1. **Spacing:** 4px/8px rhythmic scale, proper visual grouping.
2. **Color:** Quiet the chrome, restrict to a clean neutral ramp with purposeful accents.
3. **Icons:** Consistent stroke weights and styles; remove inline emojis.
4. **Copy:** Strip marketing fluff, buzzwords, and redundant subtitles. Use clear, factual copy.
5. **Type:** Restrain font weights (400, 500, 600), sentence case, balanced line-heights.
6. **Layout:** Clarify visual hierarchy and establish a single, confident primary CTA.
7. **Details:** Subtle hairline borders (0.5px / 1px), quiet ambient shadows, refined radii.
8. **Visuals:** Showcase authentic imagery, real photography, or concrete interface previews.
9. **Motion:** Subtle, purposeful transitions (<300ms) over distracting animation loops.
